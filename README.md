## 用法

- **读正文**：`408/<科目>/第N章 xxx.md`；配套习题在 `第N章 习题与解析.md`。图片在同级 `images/`，**移动单个 md 请连 `images/` 一起带走**。
- **跑代码**：
  ```bash
  g++ -std=c++17 -Wall -Wextra ch01_seqlist.cpp -o ch01_seqlist && ./ch01_seqlist
  ```
- **重跑 OCR**：见 [`_ocr/README.md`](_ocr/README.md)，内含路径约定与流水线顺序。
